# Railway Reservation Analyzer

**Project Number:** PS No. 67

## Project Description
Railway Reservation Analyzer is a Python-based project that analyzes railway booking data using Pandas and Matplotlib.

## Features
- Reads booking data from CSV file.
- Displays confirmed bookings per train.
- Calculates revenue per train.
- Skips rows with invalid fare.
- Generates a bar chart for revenue analysis.

## Technologies Used
- Python 3
- Pandas
- Matplotlib
- CSV

## Requirements
Install required libraries:

```bash
pip install pandas matplotlib
```

## How to Run
1. Keep `bookings.csv` and `railway_reservation_analyzer.py` in the same folder.
2. Open the terminal.
3. Run:

```bash
python railway_reservation_analyzer.py
```

## Project Files
- `railway_reservation_analyzer.py` – Main Python code.
- `bookings.csv` – Input booking data.
- `README.md` – Project documentation.
